手机浏览器打开上面的看板链接即可，无需安装。

## 2.0 有什么

- **名词解释**：翻转定义 + 大白话、挖空自测、易混对照、复盘队列
- **简答题**：先想采分点再对照，可收起默背，公式渲染
- **填空 / 陈述**：填空核对、选择题、陈述判断
- 日间 / 夜间 / 跟随系统
- 三套进度分开记，重置有确认
- 电脑端：空格翻转（简答为展开/收起），← → 换题，Enter 核对，1/2/3 评级后自动下一张，Esc 关浮层/回首页

计算题和看图简答题还没进看板，这是最基本的部分。
